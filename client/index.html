Create composition

The format label and name parts form a predictable composition name. Invalid filename characters are removed.

Modify selected compositions

Directly changes the selected comps. It does not add temporary layers, re-parent layers, or alter existing transforms.

Rename selected project items

Conform selected solids

With a composition active, resizes selected solid layers to its width and height. Nulls and non-solid footage are left untouched.

Create cover

Creates an editable native cover comp, so it is not dependent on a fragile Photoshop layer order.

Create checkers from selected comps

Select comps in the Project panel. Each checker holds on the chosen source frame and adds editable frame information.

To render them, select the new checker comps and use Projects → Render to outputs → Checker. Existing render-queue items are preserved.

Project maintenance

Each action uses After Effects’ native project operations and is one undo step. Select project items before reducing; reduce removes unselected dependencies.

Organize project

Selected Project-panel items remain at the root after organizing. Selected folders keep their contents unchanged. The operation never deletes existing folders.

Localize selected assets

Copies selected file-based footage into the active project’s mapped Assets/Localized folder, then relinks those footage items. Existing files are never overwritten; image sequences are skipped.

Collect project

Opens After Effects’ native Collect Files dialog. There you can choose the scope and destination, including sequences and proxies.

Composition timing

Select compositions in the Project panel. Frame changes preserve a minimum one-frame duration.

Animation and layers

Use an active composition and selected layers. Fades add opacity keyframes over the requested number of frames.

Replace selected text

Updates selected text layers at the current comp time. Existing animated text receives a keyframe at that time.
